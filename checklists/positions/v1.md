# Positions checklist, v1

For pages with a position block or a contested claim: node.md, claims.yaml and positions.yaml. If you have published for one position, say so in `interests`; a second reviewer is then needed (15.5).
Answer each question pass, fail or n/a; give a note for each fail. Yes means pass.

1. Is the question stated so that each side would accept it as the question it answers, with each definition given where they differ?
2. Is no position, in node.md or in positions.yaml, stated in the site voice?
3. Does each position have its strongest form, with a source by its proponents?
4. For each position: would a proponent accept this statement of it? (Name in the note the proponent's source you checked.)
5. Do the positions have the same parts in the same order, and the same tone?
6. Is no serious position of the literature missing? (Name the sources of a missing one in the note.)
7. Does each held_by of positions.yaml list sources that hold the position?
8. Are the objections to each position by named objectors, with sources, and stated as fairly as the position?
9. Is the evidence shared: does each position link the claims it relies on, with no claim left out because it weakens one side?
10. Are the positions in the order of their first source, not of preference or of the number of sources?
11. Does node.md use no label for a side that the side would reject, even one not in registers/loaded-words.yaml?
12. Are expert surveys reported as data (sample, response rate, wording, date), not as a vote on the question?
