# Experiment checklist, v1

For exp/<slug>/ of a node (R4): experiment.yaml, expect.yaml, run.py, results.json and figures/. The reviewer needs `exp` and `domain:<top area>`.
Answer each question pass, fail or n/a; give a note for each fail. Yes means pass.

1. Does experiment.yaml test the claim it names, as claims.yaml states it, and does scale_note state both scales right?
2. Is the control fair: the same model, data, tuning budget and seeds, with only the treatment changed?
3. Is the test of expect.yaml the right one for the claim (difference, equivalence, fit, shape, rate)?
4. Is min_effect an effect that matters for the claim, not one chosen to pass?
5. Is the power from the pilot plausible for the claimed effect?
6. Does run.py do what experiment.yaml says (arms, configs, metrics), with seeds and deterministic flags set?
7. Is each metric computed right in run.py, on the split the claim is about?
8. Do the data pins name the datasets and splits of the claim, with no test data used for training or tuning?
9. If replicates is set, does the experiment match the setting of the cited table (data, model, protocol)?
10. Does the verdict follow from results.json under expect.yaml, with no secondary metric used as the decision?
11. Does node.md state the result at the experiment's scale only, never as a reproduction of the paper's result?
12. Is a failed or inconclusive result shown as such, with the claim's label not raised?
